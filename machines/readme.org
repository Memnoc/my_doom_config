#+TITLE: Doom Emacs Installation Guide
#+AUTHOR: Memnoc
#+DESCRIPTION: Installation steps for Doom Emacs across different systems

* Arch Linux + Niri (Wayland)

** Install Everything
#+begin_src bash
# Install Emacs with native comp and pgtk (Wayland)
yay -S emacs-wayland

# Dependencies
sudo pacman -S ripgrep fd shellcheck ttf-jetbrains-mono ttf-nerd-fonts-symbols clang cmake libtool libvterm

# Clone Doom
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.config/emacs

# Clone personal config
git clone git@github.com:Memnoc/my_doom_config.git ~/.config/doom

# Remove conflicting configs
rm -f ~/.emacs
rm -rf ~/.emacs.d
#+end_src

** Add Doom to PATH
Add to =~/.zshrc=:
#+begin_src bash
export PATH="$HOME/.config/emacs/bin:$PATH"
#+end_src

Source it:
#+begin_src bash
source ~/.zshrc
#+end_src

** Run Doom Install
#+begin_src bash
doom install
#+end_src

When prompted:
- Generate envvar file? *Yes*

** Install Rose Pine Theme
#+begin_src bash
cd /tmp
git clone https://github.com/donniebreve/rose-pine-doom-emacs.git
cd rose-pine-doom-emacs
make install
#+end_src

** Final Sync
#+begin_src bash
doom sync
#+end_src

** Verify
#+begin_src bash
emacs --version
#+end_src

Desktop entry is provided by =emacs-wayland= package.

* macOS (Apple Silicon)

** Install Homebrew
If not already installed:
#+begin_src bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
#+end_src

Add to PATH:
#+begin_src bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zshrc
source ~/.zshrc
#+end_src

** Install Emacs
Using =emacs-mac= (better macOS integration, version 29):
#+begin_src bash
brew tap railwaycat/emacsmacport
brew install emacs-mac --with-modules --with-native-comp
ln -s /opt/homebrew/opt/emacs-mac/Emacs.app /Applications/Emacs.app
#+end_src

Note: This takes 15-30 minutes to compile.

** Create Machine-Specific Config
Check your hostname:
#+begin_src bash
hostname
#+end_src

Create machine file (replace =macbook= with your actual hostname):
#+begin_src bash
cat > ~/.config/doom/machines/macbook.el << 'EOF'
;;; machines/macbook.el -*- lexical-binding: t; -*-
;;; macOS specific configuration

;; Disable smooth scroll (causes slowness on macOS)
(pixel-scroll-precision-mode -1)
EOF
#+end_src

** Final Sync
#+begin_src bash
doom sync
#+end_src

** Verify
#+begin_src bash
emacs --version
emacs --batch --eval '(print (native-comp-available-p))'
#+end_src

Should return =t= for native compilation.

Launch from Applications folder or Spotlight.

** macOS Troubleshooting

*** No Application Icon After Install
If symlink wasn't created:
#+begin_src bash
ls /opt/homebrew/opt/ | grep emacs
#+end_src

Then symlink the correct path:
#+begin_src bash
ln -s /opt/homebrew/opt/emacs-mac/Emacs.app /Applications/Emacs.app
#+end_src

Refresh Spotlight:
#+begin_src bash
sudo mdutil -E /Applications
#+end_src

*** UI Feels Slow
Check if background compilation is running:
#+begin_src bash
ps aux | grep eln
#+end_src

If not, disable smooth scroll in machine config (see above).

*** Intel Mac Paths
Replace =/opt/homebrew/= with =/usr/local/= for Intel Macs.

** Installation Methods That Did NOT Work

*** Homebrew (GUI issues)
Homebrew installs a terminal-only Emacs by default. Desktop entries don't work properly due to environment/tty issues.

*** Flatpak (sandboxing issues)
Flatpak sandboxes Emacs, preventing access to =~/.config/emacs= and =~/.config/doom=. Even with filesystem overrides, Doom config doesn't load properly.

*** Snap
Requires separate installation. Not tested.

*** PPA
=ppa:kelleyk/emacs= may not have Emacs 30.

** Installation Method That Works: Build from Source

*** Build Emacs 30
#+begin_src bash
cd /tmp
git clone --depth 1 --branch emacs-30 https://git.savannah.gnu.org/git/emacs.git emacs-30
cd emacs-30
./autogen.sh
./configure --with-native-compilation --with-json --with-tree-sitter --with-pgtk --with-rsvg
make -j$(nproc)
sudo make install
#+end_src

This installs to =/usr/local/bin/emacs= and creates a desktop entry automatically.

*** Verify Installation
#+begin_src bash
which emacs
emacs --version
#+end_src

* Machine-Specific Configuration

Machine files override shared config for specific hosts. Uses hostname for detection.

** Check Your Hostname
#+begin_src bash
hostname
#+end_src

** File Location
=~/.config/doom/machines/<hostname>.el=

** Loading Mechanism (in config.el)
#+begin_src elisp
;;; Machine-specific config
(let ((machine-file (concat doom-user-dir "machines/" (system-name) ".el")))
  (when (file-exists-p machine-file)
    (load! machine-file doom-user-dir)))
#+end_src

** Example: macOS (disable smooth scroll)
#+begin_src elisp
;;; machines/macbook.el -*- lexical-binding: t; -*-
(pixel-scroll-precision-mode -1)
#+end_src

** Example: BSPWM (larger fonts)
#+begin_src elisp
;;; machines/minis350.el -*- lexical-binding: t; -*-
(setq doom-font (font-spec :family "JetBrains Mono" :size 18))
#+end_src

* Troubleshooting

** Emacs Opens Blank or Crashes
#+begin_src bash
emacs --debug-init
#+end_src

** Reset Cache
#+begin_src bash
rm -rf ~/.config/emacs/.local
doom install
#+end_src

** vterm Fails to Compile
Install dependencies:
#+begin_src bash
# Arch
sudo pacman -S cmake libtool libvterm

# Pop!_OS
sudo apt install cmake libtool libtool-bin libvterm-dev

# macOS
brew install cmake libtool
#+end_src

Then rebuild:
#+begin_src bash
doom sync
#+end_src

Or inside Emacs: =M-x vterm-module-compile RET=

** SVG Banner Not Displaying
Check SVG support:
#+begin_src bash
emacs --batch --eval '(print (image-type-available-p (quote svg)))'
#+end_src

If =nil=, rebuild Emacs with SVG support (Pop!_OS) or install =librsvg= (Arch).

** "Invalid image specification" Error
Either SVG support missing or image file not found. Check:
#+begin_src bash
ls ~/.config/doom/images/banner.svg
#+end_src

Comment out in =config.el= to bypass:
#+begin_src elisp
;; (setq fancy-splash-image (concat doom-user-dir "images/banner.svg"))
#+end_src

** fd-find Not Found (Pop!_OS)
#+begin_src bash
sudo ln -s $(which fdfind) /usr/local/bin/fd
#+end_src

** doom Command Not Found
Use full path:
#+begin_src bash
~/.config/emacs/bin/doom sync
#+end_src

Or source your shell config:
#+begin_src bash
source ~/.zshrc
#+end_src

* Notes

** System Differences
| Feature        | Arch + Niri             | Arch + BSPWM    | macOS                  | Pop!_OS                |
|----------------+-------------------------+-----------------+------------------------+------------------------|
| Emacs install  | =yay -S emacs-wayland=  | =pacman -S emacs= | =brew install emacs-mac= | Build from source      |
| Emacs version  | Latest                  | Latest          | 29 (or 30 with plus)   | 30                     |
| fd package     | =fd=                    | =fd=            | =fd=                   | =fd-find=              |
| vterm deps     | =libvterm=              | =libvterm=      | Automatic              | =libvterm-dev=         |
| Desktop entry  | Automatic               | Automatic       | Symlink to /Applications | Automatic (from build) |
| Smooth scroll  | Works                   | Works           | Disable (slow)         | Works                  |
